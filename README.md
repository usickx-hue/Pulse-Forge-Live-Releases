# Pulse Forge Live

Create music videos automatically from your music and media.

Pulse Forge Live is a Windows desktop application for creating ready-to-publish music videos from tracks, images and videos. Customize visualizers and effects, preview the result and render the finished video.

## Features

- Automatic music video creation
- Live Preview
- Audio-reactive visualizers and beat-synced effects
- Auto Zoom, Auto Scenes, particles and glow
- Image or video backgrounds
- Separate or combined rendering
- 16:9, 9:16 and 1:1 formats
- 720p, 1080p, 1440p and 4K
- 30 / 60 FPS
- Russian, Ukrainian and English interface
- Built-in updater
- Export and import user presets

## How it works

1. Add your music.
2. Add an image or video.
3. Choose visualizer and effects.
4. Preview the result.
5. Select resolution and FPS.
6. Render your video.

## Installation

1. Download Pulse Forge Live Setup.exe.
2. Run the installer and complete installation.
3. Launch Pulse Forge Live.
4. Select your interface language on first launch.

The current Windows build is not digitally signed yet, so Windows SmartScreen may display a warning.

## System requirements

- Windows 10 or Windows 11
- 64-bit system
- GPU acceleration recommended for high-resolution rendering
- Enough free disk space for rendered videos
